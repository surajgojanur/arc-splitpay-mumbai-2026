# Collaboration
Suraj owns web/**, root configuration, .github/**, README.md, CONTRIBUTING.md, AI_USAGE.md, docs/architecture.md, docs/demo.md and docs/arc-studio.md.
Kishore exclusively owns chain/** and docs/chain-handoff.md after bootstrap.

Use separate clones/worktrees. Branches: feat/suraj-frontend and feat/kishore-contract. Never develop directly on main after bootstrap. No force pushes or unverified merges. Do not invite collaborators automatically.

Read assigned GitHub issues before work. Acknowledge interface changes there before implementation. Refresh issues at milestones. Open draft PRs, post validation and request review. Close only after acceptance.

Every coordination comment uses:
```
STATUS: STARTED | BLOCKED | READY_FOR_REVIEW | DONE
OWNER:
ISSUE:
BRANCH:
WHAT CHANGED:
CONTRACT/API IMPACT:
TESTS:
BLOCKERS:
REQUEST TO OTHER DEVELOPER:
```

Never commit secrets. MIT applies to newly authored code; retain third-party notices.
